# 火箭发射 · Rocket Launch

浏览器里的多级火箭装配与发射游戏。搭配引擎、燃料箱与分离器，把火箭送过 100 km 卡门线。

## 页面

- `index.html` —— 主页。发射场全景，点**火箭制造大楼**进车间，点**雷达站**开机库。
- `game.html` —— 制造车间 + 飞行。
- 机库记录抵达卡门线的飞船（存于浏览器 localStorage），含一个系统预置三级火箭。

## 玩法

1. **装配** —— 从左侧零件库选零件，自下而上搭建。注意起飞推重比要大于 1。
2. **发射** —— 点「发射」点火升空。
3. **分离** —— 本级燃料耗尽时按 **空格**（或点「分离」）抛掉空壳，让上面级点火。
4. **目标** —— 越过 100 km 即抵达太空。
5. **登月** —— 入轨后点「继续飞行」（速度不损失），再爬 5 km 抵达月球，
   解锁成就「阿波罗计划」。可选择降落：燃料调整为剩余飞船满载油量的 30%，
   从 1 km 高度、月球重力（地球的 2/3）、真空无阻力条件下反推着陆，触地需低于 16 m/s。

## 彩蛋

局内双击发射台的混凝土平台或塔架（点山体无效），本局推力 +40%，尾焰由黄橙转为淡蓝淡紫（登月后失效）。

## 零件数值

| 引擎 | 推力 | 耗油/秒 |  | 燃料箱 | 容量 |
|---|---|---|---|---|---|
| 大 | 30 | 3 |  | 大 | 100 |
| 中 | 20 | 2 |  | 中 | 60 |
| 小 | 15 | 1 |  | 小 | 20 |

分离器把火箭从所在位置断成两截，分离瞬间给上面级一点推力。

## 技术

纯静态页面，无构建、无依赖。`parts.js`（零件数值）/ `physics.js`（物理与分级）/ `game.js`（渲染与交互）。

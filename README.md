# 火箭发射 · Rocket Launch

浏览器里的多级火箭装配与发射游戏。搭配引擎、燃料箱与分离器，把火箭送过 100 km 卡门线。

## 玩法

1. **装配** —— 从左侧零件库选零件，自下而上搭建。注意起飞推重比要大于 1。
2. **发射** —— 点「发射」点火升空。
3. **分离** —— 本级燃料耗尽时按 **空格**（或点「分离」）抛掉空壳，让上面级点火。
4. **目标** —— 越过 100 km 即抵达太空。

## 零件数值

| 引擎 | 推力 | 耗油/秒 |  | 燃料箱 | 容量 |
|---|---|---|---|---|---|
| 大 | 30 | 3 |  | 大 | 100 |
| 中 | 20 | 2 |  | 中 | 60 |
| 小 | 15 | 1 |  | 小 | 20 |

分离器把火箭从所在位置断成两截，分离瞬间给上面级一点推力。

## 技术

纯静态页面，无构建、无依赖。`parts.js`（零件数值）/ `physics.js`（物理与分级）/ `game.js`（渲染与交互）。
素材由 GPT-IMAGE-2 生成后去背、压缩。
